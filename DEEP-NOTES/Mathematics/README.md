# Mathematics Deep Notes

_A structured map of mathematics, grouped into seven areas. One file per topic, Pattern B concept notes with a mermaid diagram in each Overview._

## Groups

| Group                     | Description                                                                     | Link                                             |
| ------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------------ |
| **Foundations**           | Logic, proof, set theory, and category theory underpinning all of mathematics.  | [Foundations/](./Foundations/)                   |
| **Number Theory**         | Integers, primes, and the number systems, from arithmetic to algebraic numbers. | [Number-Theory/](./Number-Theory/)               |
| **Discrete Mathematics**  | Countable structures: combinatorics, graphs, order, and theory of computation.  | [Discrete-Mathematics/](./Discrete-Mathematics/) |
| **Algebra**               | Structures and symmetry: groups, rings, fields, and linear algebra.             | [Algebra/](./Algebra/)                           |
| **Analysis**              | Limits, calculus, differential equations, and functional analysis.              | [Analysis/](./Analysis/)                         |
| **Geometry and Topology** | Shape and space: Euclidean, differential, algebraic geometry, and topology.     | [Geometry-Topology/](./Geometry-Topology/)       |
| **Applied Mathematics**   | Mathematics in the world: modeling, optimization, probability, and information. | [Applied-Mathematics/](./Applied-Mathematics/)   |
